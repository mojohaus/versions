Versions

The Versions Maven Plugin shows which dependencies, plugins and properties in your POM have newer versions, and updates them for you. It also sets the version of a multi-module project in one step.

Quick start

Run these from the directory that holds your pom.xml. No change to the POM is needed.

List dependencies with newer versions:

mvn versions:display-dependency-updates

List plugins with newer versions, taking each plugin's Maven prerequisite into account:

mvn versions:display-plugin-updates

Update the version properties of your POM to the newest releases:

mvn versions:update-properties

Set the version of a project and all its modules:

mvn versions:set -DnewVersion=2.0.0

For contributors

The plugin is built from these modules:

  • Versions API: the extension API for the plugin.
  • Versions Common: code shared by the plugin and the Enforcer rule.
  • Versions Model and Versions Model Report: the Modello models of the rule sets and reports.
  • Versions Test: test utilities.
